<summary>⚙️ How the live sections above work</summary>
<br/>

Both the 3D contribution graph and the snake animation are generated by GitHub Actions living in this repo, under <code>.github/workflows/</code>. They need one-time setup:

1. Go to **Settings → Actions → General → Workflow permissions** in this repository and select **Read and write permissions**, then save.
2. Go to the **Actions** tab, open each workflow (`Generate 3D Contribution Graph`, `Generate Contribution Snake`), and click **Run workflow** once to generate the first image — after that they refresh automatically on the daily schedule.
3. The snake workflow publishes to a branch named `output`; the 3D graph commits straight to `main`. Both are already referenced above.
